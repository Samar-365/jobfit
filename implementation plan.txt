PROJECT OVERVIEW
----------------
Product:          JobFit
Type:             Local-first AI Career Assistant
Primary Goal:     Compete for overall Hacktoberfest prize & "Best Use of Gemma"
Core Technologies:
  - AI Engine:    Gemma (initial model candidate: gemma3:1b) via Ollama
  - Frontend:     React, Vite, TypeScript, Vanilla CSS (Pastel 3D theme)
  - Backend:      Python 3.10+, FastAPI, Pydantic v2
  - Storage:      SQLite (metadata/applications) & Local Filesystem (documents)
  - Testing:      pytest (backend), Vitest/Playwright (frontend), synthetic benchmarks

Core Principles:
  1. 100% Local Inference & Privacy: No career documents sent to cloud LLMs.
  2. Grounded Evidence: Every match or gap must cite verifiable resume text.
  3. No Hallucinations: Never invent experience, metrics, or credentials.
  4. Non-Predictive Matching: Deterministic, transparent score; no fake "ATS" guarantees.
  5. Phased Gate Execution: Each phase must be independently verified before advancing.

PHASE 2: LOCAL GEMMA INTEGRATION & MULTI-FORMAT RESUME PARSING
------------------------------------------------------------------------------

PHASE 3: EVIDENCE-BACKED JOB MATCHING & SKILL GAP ANALYSIS
------------------------------------------------------------------------------
Goal: Implement the core differentiating capability: explainable matching with cited evidence.

Tasks:
  [x] 3.1 Job Description Ingestion:
        - Endpoint: `POST /api/jobs` (paste text, company, role title).
        - Structured requirement extraction (Must-Have vs. Nice-to-Have qualifications).
  [x] 3.2 Evidence Matching Engine (`matcher.py`):
        - Prompt Gemma to evaluate each job requirement against parsed resume data.
        - For each requirement, classify status:
          * `EXACT_MATCH`: Explicit resume evidence found (quote exact snippet).
          * `PARTIAL_MATCH`: Indirect or transferable experience identified.
          * `NOT_MENTIONED`: No evidence present in the submitted document.
          * `UNASSESSABLE`: Cannot be determined from the document.
        - Strict constraint: Missing evidence must NEVER be reported as "user lacks this skill".
  [x] 3.3 Deterministic Scoring Engine (`scoring_engine.py`):
        - Transparent mathematical formula based on verified requirements ratio:
          Score = (Weighted Matched Requirements / Total Requirements) * 100.
        - Zero black-box hallucinated scoring.
        - Explicit UI disclaimers: "Estimated match based on supplied text. Not an ATS guarantee."
  [x] 3.4 API & UI Integration:
        - Endpoint: `POST /api/analyses` and `GET /api/analyses/{id}`.
        - UI: Match Summary Card with component score breakdowns.
        - UI: Evidence Matrix displaying each requirement alongside verbatim resume quotes.
        - UI: Actionable Gap List with recommendations on how to address unevidenced areas.

Deliverables:
  - Complete resume-to-job matching pipeline with cited source quotes.
  - Transparent match breakdown UI.

Gate Criteria:
  - Demonstration that every positive match includes verifiable resume evidence.

------------------------------------------------------------------------------
PHASE 4: GROUNDED RESUME TAILORING & COVER LETTER DRAFTER
------------------------------------------------------------------------------
Goal: Empower users to improve resume wording and generate cover letters without fabricating claims.

Tasks:
  [x] 4.1 Truthful Resume Tailoring Engine (`tailoring.py`):
        - Select specific bullet point from parsed resume.
        - Provide relevant target job requirements to Gemma.
        - Guardrail prompt:
          * Align terminology and action verbs to the job description.
          * STRICTLY FORBID inventing achievements, metrics, companies, or degrees.
          * If a metric is missing, retain the original factual core.
  [x] 4.2 Side-by-Side Tailoring UI:
        - Diff view showing Original text vs. Suggested text.
        - One-click "Accept", "Edit Manually", or "Reject" actions.
        - Copy revised bullet to clipboard.
  [x] 4.3 Context-Grounded Cover Letter Generator (`cover_letter.py`):
        - Prompt utilizing user resume, target job description, and optional user motivation notes.
        - Strict placeholder policy: When key details are unstated, output explicit tokens
          such as `[Specific reason why you admire Company X]` rather than making up stories.
        - In-browser markdown editor for instant customization.
  [x] 4.4 Tests:
        - Adversarial test cases confirming the model rejects prompts asking to fabricate degrees.

Deliverables:
  - Resume bullet point rephraser with side-by-side diffing.
  - Cover letter generator with placeholder protections and markdown export.

Gate Criteria:
  - Automated tests prove that tailored suggestions never introduce unevidenced credentials.
